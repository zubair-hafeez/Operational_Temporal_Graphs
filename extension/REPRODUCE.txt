EXPERIMENT COMMANDS (HISTORICAL RECIPE; DO NOT OVERWRITE FINISHED RUNS)
  python extension/fetch_pilots.py --source SOURCE
  python extension/prepare_pilots.py --source SOURCE
  python extension/run_pilots.py --source SOURCE --seed SEED --epochs EPOCHS --marginals-only --tag replication_v2 [--ablations] [--device cuda:0]
  python extension/joint_controls.py --source SOURCE --tag controls_v2
  python extension/freeze_confirmation.py
  python extension/confirm.py --source SOURCE

SOURCE is uci, azure_full, or bpi2014. Seeds are 0,1,2. UCI uses 30 epochs;
Azure/BPI2014 use 20. Use --ablations for UCI and Azure. Three seeds are averaged,
never best-seed selected. HGB and neural features share the same observed prefix;
the temporal HGB receives the same flattened tokens as attention. The complete
saved command/config and source snapshots are in each run. Confirmation uses
512 draws, sampling seeds 0/1/2, and fair CRPS; fitting/pilots use empirical CRPS.
All models remain fixed in confirmation. Dependence is not refit to final scores.

Preparation, fitting and confirmation refuse to overwrite their output dirs.
Do not delete completed scientific records to rerun them. Exact frozen-model
confirmation requires a separate workspace with the frozen inputs and without
the final output directories; use read-only links for large unchanged inputs.
A hardware-dependent retraining will produce different model hashes: it is a
replication, not an exact verification of the original freeze. Changing a frozen
file in place is prohibited. A new experiment needs distinct names and an honest
statement that these final periods have already been inspected.

POST-CONFIRMATION NUMERICAL CHECKS (NO TRAINING OR MODEL SELECTION)
  python extension/count_sensitivity.py --source uci
  python extension/count_sensitivity.py --source azure_full
  python extension/count_sensitivity.py --source bpi2014
Uses 1,024 draws, seed 0, all origins, and the predefined controls plus each
development-selected coherent arm. Fair count CRPS is compared to seed-0
512-draw scores. It does not certify every joint-tail metric's sampling error.
