CLEANUP AND REPRODUCTION
The two release ZIPs were redundant packaged copies. Every archive member
was verified and retained; unique old versions are under archives/.
Large byte-identical immutable data arrays and a shared figure now use
relative links while preserving the paths required by the experiments.
Do not overwrite frozen inputs; new work needs separate output paths.
No manuscript text, model values, predictions or reported results changed.

From this folder, using the documented Python 3.10 environment:
  python scripts/organized_review.py
  python revision/audit_revision_artifacts.py

Reconstruct a portable review ZIP only when needed:
  python scripts/organized_review.py --restore revision --output /tmp/otg_revision_review.zip
Use --restore original for the earlier package. The tool checks every member
hash. It does not promise the original ZIP's container checksum.

archives/ORGANIZATION_MANIFEST.json records all retained archive members,
removed duplicate PDFs and duplicate-link targets. Historical notes may
mention retired ZIPs; this guide describes the current layout.
